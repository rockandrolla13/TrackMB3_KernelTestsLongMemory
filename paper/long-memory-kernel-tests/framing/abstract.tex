\begin{abstract}
Kernel tests assume independent observations, yet many ordered data have long memory. We give one decision rule for testing independence on such data. Remove the seasonal mean and scale from each series. Then run the Hilbert--Schmidt independence criterion (HSIC) with circular shifts, which realign one series against the other to build the reference distribution. In our simulations at $n=2000$, this rule rejected $3.4\%$--$7.0\%$ of true nulls at a nominal $5\%$. At matched size it lost at most $4.9$ points of power to the best other HSIC rule. The rule has limits. No long-memory theory covers it, and a slow scale drift still raises it to $9.7\%$. Two findings support the rule. First, the critical-value rule and the feature rank set the false-alarm rate. Split-sample maximum mean discrepancy with wild multipliers rejects $27.1\%$ of stationary series at Hurst index $H=0.8$.
